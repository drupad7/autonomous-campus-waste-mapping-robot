# Autonomous-Campus-Waste-Mapping-Robot

Autonomous 2WD robot designed to patrol predefined campus routes , detects , classify the waste ,record waste locations , photographs and generate patrol reports.


## Core Architecture 

    > Android Phone (A) - Robot computer
    > Andriod Phone (B) - Controller
    > ESP - 32          - Microcontroller
    > TB6612FNG         - Ultra Sonic Sensors
    > MPU6050           - IMU
    > Wheel encoders    - Odometry
    > Android Camera    - Waste Detection
    > On-device AI      - Waste Classification
